# Ask contextual questions

Before asking the user a question, including in Superpowers workflows or question tools:

1. State the problem and context needed to decide.
2. Explain meaningful options and trade-offs, recommending one when justified.
3. Ask one clear, focused question.

Keep straightforward questions proportionately concise. Do not invent choices or trade-offs.
